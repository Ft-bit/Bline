# Brightline: setup guide

## 1. Replace the placeholders
Search all files and replace:
- `YOUR-TAG-20` with your Amazon Associates tracking ID (you get it after your account is approved; until then leave the links as they are)
- `YOUR-EMAIL@example.com` with your real contact email (contact.html)

## 2. Publish on GitHub Pages (free)
1. Create a new public repository on GitHub, for example `brightline`.
2. Upload all files in this folder to the repository root (index.html must be at the top level).
3. Go to Settings > Pages. Under "Build and deployment" choose "Deploy from a branch", select `main` and `/ (root)`, then Save.
4. After a minute your site is live at `https://YOUR-USERNAME.github.io/brightline/`.
5. Paste that URL into the "Enter Your Website(s)" box in Amazon Associates.

## 3. Before you apply
- Make sure the site loads and all links work.
- Keep the Affiliate Disclosure and Privacy Policy pages and the footer statement.
- Add more guides over time. Copy air-fryers.html as a template.
- Amazon expects 3 qualifying sales within 180 days of approval, so share your guides where US or UK shoppers will see them.
